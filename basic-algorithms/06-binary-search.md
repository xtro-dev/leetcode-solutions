## Problem: Binary Search (Easy-Medium)

**Link:** https://leetcode.com/problems/binary-search/

### Approach

Binary search repeatedly divides the sorted array into two halves. The target is compared with the middle element, and the half that cannot contain the target is discarded.

### Complexity

- Time: O(log n)
- Space: O(1)

### Notes

Binary search requires the input array to be sorted.
